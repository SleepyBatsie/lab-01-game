# Space Game — Lab 07: V8, пам'ять і тести

![CI](https://github.com/SleepyBatsie/lab-01-game/actions/workflows/ci.yml/badge.svg)

Багатокористувацька 2D-гра в реальному часі (`shared/`, `server/`, `client/`), оптимізована під двигун **V8** (пули об'єктів `ObjectPool`, просторовий хеш `SpatialHash`, усунення алокацій у гарячому циклі) та покрита тестами (**Vitest**, **fast-check**, **Playwright**) і навантажувальним тестуванням.

![Gameplay Demo](demo-lab05.gif)

## Результати профілювання V8 (30 с гри з 8 ботами)

| Метрика (30 с, 8 ботів + гравець) | До (Lab 06) | Після (Lab 07) | Оптимізація |
| :--- | :---: | :---: | :--- |
| **Час кадру p50 (клієнт)** | 1.85 ms | **0.92 ms** | Scratch-буфери поза `renderLoop` |
| **Час кадру p95 (клієнт)** | 4.90 ms | **1.64 ms** | Перевикористання масивів без `new` |
| **Час кадру p99 (ціль < 16.7 ms)** | 18.40 ms | **2.85 ms** | Усунуто сплески Minor GC |
| **Паузи GC** | 6-11 ms | **< 0.4 ms** | `ObjectPool` для куль і частинок |
| **Колізії на сервері** | O(N*M) | **SpatialHash O(N)** | Пошук у комірках 80x80 px |

### Висновок про Web Worker
Фізику частинок винесено в `client/src/particleWorker.ts` (`Transferable Float32Array`). При 300-600 частинках витрати на `postMessage` (~0.3 ms) перевищують розрахунок у пулі головного потоку (~0.08 ms), тому за замовчуванням Worker вимкнено (перемикач залишено для тесту).
